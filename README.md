# BioFAIR 2026 Workflow Interoperability Sprint

**Hybrid sprint bringing together contributors from Bioconductor, Galaxy, Nextflow, nf-core, WDL and related workflow communities.**

15-17 September 2026
Milton Keynes, United Kingdom

## Overview

The BioFAIR Workflow Interoperability Sprint brings together developers, users, infrastructure providers and community leaders from across the bioinformatics workflow ecosystem.

The event focuses on improving interoperability between platforms and projects including:

- Bioconductor
- Galaxy
- Nextflow
- nf-core
- WDL
- TES and workflow execution services
- Related open-source infrastructure projects

The sprint will be run as a hybrid event, with opportunities for both in-person and remote participation. Those interested in participating are encouraged to join the Zulip channel and introduce themselves.

## Goals

Potential topics include:

- Improving interoperability between workflow platforms
- Packaging and execution of Bioconductor methods
- Workflow generation and automation
- Galaxy tool and workflow development
- Nextflow and nf-core integration
- WDL integration and testing
- Documentation and community resources
- FAIR and reproducible workflows
